# Overview

Yak Ops is a big data governance platform that connects data integration, development, and governance in one place.

## Platform Capabilities

- **Data Integration:** connect sources and explore batch or real-time synchronization.
- **Data Development:** understand tasks, workflows, and scheduling.
- **Data Governance:** explore data assets, lineage, and data quality.

For details, browse the [Products catalog](/docs/products/overview).
