# Before You Begin

Prepare your environment before starting your first Yak Ops deployment.

## Prerequisites

- Docker Engine and Docker Compose v2 for the documented container-based deployment.
- Access to the [Yak Ops source repository](https://github.com/weifuwan/yak-ops).
- Appropriate CPU, memory, disk space, and host ports for the deployment bundle.
- Database access and permissions if you plan to connect an external source.

The required versions, ports, and runtime settings depend on the deployment bundle you choose. Check its configuration before starting.
