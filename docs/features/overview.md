# Features

Yak Ops brings common data operations into one workspace. This page is a lightweight map of the main product modules so new users can quickly understand what each area is for.

Detailed guides can be added over time as each capability evolves.

## Data Integration

### Data Sources
Manage reusable connections to databases and data platforms.

### Offline Sync
Move data between systems with batch synchronization, including single-table, multi-table, and script-based tasks.

### Realtime Sync
Create and operate real-time data synchronization tasks.

## Data Development

### Development Tasks
Create and manage data development jobs from a central workspace.

### Release Center
Review and manage the release lifecycle of development tasks.

### Execution Records
Inspect task runs and execution history.

## Workflow

### Workflow Definitions
Combine multiple tasks into reusable workflows.

### Scheduling
Configure when workflows should run.

### Workflow Instances
Track workflow executions and inspect individual runs.

## Resource Management

### File Resources
Manage files and reusable resources used by data tasks.

## Data Quality

### Quality Overview
See the current state of data quality at a glance.

### Table Monitoring
Configure quality monitoring for important tables.

### Rule Templates
Reuse common data quality rules across monitoring tasks.

### Execution Records
Review quality check runs and their results.

## Data Consumption

### Datasets
Organize and manage datasets for downstream use.

### Dashboards
Build dashboards to explore and present data.

### Data Lineage
Understand relationships and dependencies between data assets.

### Digital Screens
Create large-screen visual experiences for operational and business data.

## Data Services

### API Marketplace
Browse and manage published data APIs.

### API Access & Debugging
Call and debug data services from the platform.

### Runtime Overview & Call Logs
Observe service activity and review API call history.

## System Management

### Users, Departments & Roles
Manage users, organizational structure, roles, and permissions.

### Operation Logs
Review important platform operations for administration and auditing.

---

Yak Ops is under active development, so available capabilities may continue to evolve. This page focuses on the current product modules rather than implementation details.
