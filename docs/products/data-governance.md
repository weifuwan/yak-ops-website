# Data Governance

Data Governance covers capabilities for understanding, managing, and improving data reliability.

## Capability areas

- **Data Quality** — checks and monitoring for trustworthy data.
- **Data Lineage** — relationships and dependencies among resources.
- **Data Assets** — visibility and organization of data assets.
- **Datasets** — reusable data collections.
- **Data Services** — expose data through managed services.
- **Metrics** — shared business measures.
