# Yak Ops AI

Yak Ops AI is the documentation home for AI-assisted experiences planned for Yak Ops 2.0.

> **Roadmap:** The following capability areas describe a proposed documentation structure, not functionality already shipped.

## AI Assistant

Natural-language assistance for understanding platform capabilities and tasks.

## AI Data Integration

Assistance with synchronization configurations, field mappings, and transformation rules.

## AI Data Development

SQL authoring assistance and workflow creation support.

## AI Data Governance

Help exploring data assets, quality, and lineage.

## AI Configuration

Model integration, service settings, and access-control documentation.

## Release information

See [Release 2.0](/docs/release-2.0) for future availability, release notes, and compatibility guidance. Detailed instructions will be added as features are delivered.
