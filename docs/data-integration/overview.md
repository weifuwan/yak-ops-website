# 数据集成概览

数据集成负责把外部数据稳定地送入后续处理链路。Yak Ops 将离线同步和实时同步作为两类不同的运行模型，而不是用同一套参数强行覆盖所有时效场景。

## 离线同步与实时同步

### 离线同步

离线同步更适合按批次、按时间窗口或按明确边界处理的数据。阅读任务详情时，重点关注数据范围、增量条件、运行耗时和失败后的可恢复性。

### 实时同步

实时同步更关注持续运行状态、延迟、上下游连接和异常恢复。它的判断标准通常不是“一次任务跑完”，而是链路能否持续稳定地工作。

## 为什么运行记录很重要

配置只说明“希望系统怎么运行”，运行记录才说明“系统实际上发生了什么”。排查同步问题时，建议把下面几类信息放在一起看：

- 任务当前状态与关键时间点；
- 读取端和写入端的基本信息；
- 实际处理量与异常信息；
- 失败发生在哪个阶段；
- 重试或再次运行是否会改变数据边界。

## 和其他模块的关系

同步成功并不等于数据已经可用。数据进入目标位置后，还可能继续进入数据开发任务、质量检查和血缘分析。因此集成模块输出的运行信息，应当能成为后续治理链路的上下文，而不是一个孤立的“成功/失败”标签。
